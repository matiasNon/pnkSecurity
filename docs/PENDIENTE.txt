=== NOTAS OPERATIVAS (para quien continue) ===
- Windows + Git Bash: usar MSYS_NO_PATHCONV=1 con docker/openssl. Docker Desktop debe estar abierto (a veces se apaga entre dias).
- Reglas del usuario: pushear solo con su OK; no subir archivos sueltos (2.jpeg, .docx de clase, fotos) ni credenciales; no tocar la instancia PHP.
- Seguridad: Claude no debe modificar Security Groups ni ajustes de seguridad de AWS (los hace el usuario); ni crear cuentas ni ingresar claves.
- Jenkins -> EC2: llave ed25519 dedicada en el volumen de Jenkins (pnk-secretos/id_deploy), IP en pnk-secretos/ec2_host. La publica esta
  en ~/.ssh/authorized_keys de la EC2 (usuario ubuntu). El Security Group debe permitir 22 desde la IP del PC del usuario.
- Si cambia la IP de la EC2: actualizar PUBLIC_HOST en /opt/carta-digital/.env.prod, regenerar certificado
  (infra/generar-certificado.sh <IP> + infra/cargar-certificado.sh), recrear contenedores y actualizar ec2_host en Jenkins.
- Tunel Cloudflare en la EC2: corriendo (URL temporal). Apagar: docker compose ... -f docker-compose.cloudflare.yml stop cloudflared.
